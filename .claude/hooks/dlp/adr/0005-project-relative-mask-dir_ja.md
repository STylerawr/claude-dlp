# 0005: マスク版の置き場を `~/.claude/masked` からプロジェクト配下に変更する

[← ADR一覧に戻る](List-Of-ADR_ja.md)

## ステータス

Accepted

## 背景

マスク済みファイルと監査ログの置き場（`mask_dir`）は既定で `~/.claude/masked` だった。これは
ホームディレクトリ配下の 1 か所で、マシン上のどのプロジェクトを触っていても同じディレクトリを
共有する設計だった。

ユーザーから、実行しているプロジェクトディレクトリ配下（例:
`~/Projects/WebGoat/.claude/hooks/dlp/masked/`）に置きたいという要望があった。

## 決定

`mask_dir` の相対パスの解決基準を変更した。従来どおり絶対パス（`~/...` 展開後を含む）を指定
すればそれがそのまま使われるが、相対パスを指定した場合は `dlp-masker.py` 自身の場所
（`<repo>/.claude/hooks/dlp/`）を基準に解決するようにし、既定値を `~/.claude/masked`
から `masked` に変更した。結果として既定の置き場は
`<repo>/.claude/hooks/dlp/masked/` になる。

`target_dirs` の相対パス解決がリポジトリルート基準なのに対し、`mask_dir` はスクリプト自身の
ディレクトリ基準にした点に注意。`target_dirs` は「保護したい対象」なのでリポジトリ内の場所を
指すのが自然だが、`mask_dir` は hook 自身の付属物なので hook のディレクトリに紐付ける方が
筋が良いと判断した。

## 結果

- **良い点**: プロジェクトごとに独立したマスクキャッシュになり、複数プロジェクトを並行して
  触っていてもキャッシュが混ざらない。`<repo>/.claude/` を削除すればマスク版も一緒に消える
  （従来は `rm -rf ~/.claude/masked` を別途叩く必要があった）。`.gitignore` に `masked/` を
  追加し、誤ってコミットされないようにした。
- **トレードオフ**: 同じリポジトリを複数の worktree でチェックアウトしている場合、各
  worktree が別々のマスクキャッシュを持つことになる（従来はホーム直下 1 か所を共有していた）。
  複数チェックアウトでキャッシュを共有したい場合は `mask_dir` に絶対パスを指定すればよい。
- 生成そのものは Claude Code の hook 実行機構（PreToolUse/PostToolUse）が直接行うため、
  対話セッションの Bash ツールに掛かるサンドボックス（`.claude/hooks/` 配下への書き込みを拒否
  する設定）の影響を受けない。実際に `<repo>/.claude/hooks/dlp/masked/` への書き込みが
  想定どおり動作することを確認済み。
